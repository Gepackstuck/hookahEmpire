# Hookah Empire — Design Pack v0.1

Эта папка содержит начальную design/agent-документацию для Garage MVP.

## Файлы

- `AGENTS.md` — постоянные инструкции для агента (Беброид).
- `docs/GDD.md` — game-design источник истины.
- `docs/MVP_PLAN.md` — implementation roadmap M0–M11.
- `docs/ARCHITECTURE.md` — техническая структура и data contracts.
- `docs/PROGRESS.md` — milestone-трекинг и открытые решения.
- `docs/RECIPE_RESEARCH.md` — workspace для flavor-combination research.
- `docs/DEV_SETUP.md` — локальная разработка: запуск Godot, проверки, тесты.

## Что сделано по этапам (M)

Краткое описание каждого завершённого этапа. Подробности и статусы — в `docs/PROGRESS.md`, план — в `docs/MVP_PLAN.md`. Описание добавляется в конце каждого этапа.

- **M0 — Foundation.** Структура проекта, загрузка главной сцены, GameState и SaveService, логирование, data-каталоги и скрипты проверок.
- **M1 — Garage + Player.** Изометрический гараж по JSON-данным, кальянщик с ходьбой и камерой, столкновения, подсказки и интерактивные объекты.
- **M2 — Dialogue + Friends.** Диалоговая система на данных, сюжетные биты и приход первого гостя (Денис), сюжетные флаги и эффекты.
- **M3 — Ingredients + Recipes + Recipe Book.** Каталог ингредиентов, смеситель вкусов, оценка рецептов и книга рецептов с сохранением.
- **M4 — Quick Preparation.** Быстрое приготовление кальяна, подача гостю, его реакция и совместное курение.
- **M5 — Manual Preparation.** Мини-игра ручной забивки (ингредиенты, набивка, фольга, дырки, угли, розжиг), кальянная полка, шланг и мундштуки.
- **M6 — Guest Session + Scoring.** Полная сессия гостя (Денис и Макс): итоговая оценка, оплата, прощание, итоговая карточка, повторные визиты.
- **M7 — Heat + Charcoal + Re-preparation.** Жар кальяна (холодно/жарко/сгорели) и штрафы, замена углей щипцами, просьба гостя перезабить, режим NPC с «забывчивым» автопилотом; для тестов — окно статистики 📊 со скоростью ×10, цикл гостей Ден → Макс и разнообразный простой кальянщика.
- **M8 — Trends + Economy + MVP Progression.** Пять трендов в авторской ротации (меняются каждые 3 визита гостей) влияют на оценку через TrendFit; деньги и репутация: оплата зачисляется, ингредиенты списываются при подаче кальяна (пять базовых ингредиентов бесплатны, платный рецепт блокируется при нехватке денег), платные также угли и мундштуки, перезабивка оплачивается заново; панель статуса слева вверху; в книге рецептов значки тренда и ⭐ у сильных рецептов; цель MVP «сильные рецепты» (в M10 сокращена до одного; балл ≥75 минимум при 2 разных трендах) запускает финальный диалог с намёком на будущих гостей. Для тестов — кнопки в окне статистики (смена тренда, +1000 💰, 💰 → 0, сброс цели) и строки экономики.
- **M9 — Furniture + Garage Customization.** Режим мебели по кнопке 🛋️: панель слева на всю высоту с вкладками «Магазин» и «В наличии», карточки-сетка с миниатюрами. Каталог из 8 предметов (малый стол, стул, диван, картина, торшер, растение, ковёр, малая полка); покупка и продажа (30% цены) с подтверждением по центру экрана и плашками-уведомлениями. Расстановка с шагом в полклетки: предмет тянется из списка или прямо в мире, ПКМ/R — поворот, ПКМ по предмету в гараже — меню (переместить / повернуть / убрать); зелёный/красный «призрак», подсветка при наведении, пунктирная сетка, камера двигается зажатым колесом мыши. Ковёр лежит под другой мебелью, растение ставится на стол и полку. Мебель — декор: проходы к рабочим местам всегда остаются свободными, комфорт и атмосфера дают небольшой бонус к итоговой оценке гостя (не больше +3). Пока открыт режим мебели, игра стоит на паузе.
- **M10 — 20-minute Intro Vertical Slice.** Вводный срез на ~20 минут: гости Денис, Макс и Иван приходят по сюжету, разблокировки идут по числу обслуженных гостей (ручная забивка сразу, быстрый режим после двух гостей, мебель после первого, автопилот после третьего). Бэн — друг без заказов: приносит диван в подарок, сидит, говорит по телефону и ходит по гаражу, изучая столы, кальяны, полки и книгу рецептов. Панель цели в правом верхнем углу ведёт по шагам (в т.ч. подсказка, что такое «сильный рецепт»); цель MVP — один сильный рецепт, после неё открытая концовка с уведомлением, что гостей станет больше. Ручная забивка доработана: честные подсказки, кнопка «Далее» всегда видна, угли греются по одному и всегда три, рецепт в окне приготовления — последняя сборка (ⓘ-подсказка). Жар реже; при 95% гость перестаёт курить до замены углей, угли меняются со стороны корзины. Прочее: картины на стене и в магазине (🔍) открываются в просмотрщике, бумбокс на полке с 8-битным мотивом, стакан молока с репликами, реплика «Я сейчас!» при ожидающем госте, затемнение фона при открытых окнах. Для тестов: автопилот ×10 (после третьего гостя), в окне статистики — тайминги интро, журнал визитов (заказ, тренд, рецепт) и список сильных рецептов; цена замены углей снижена до 30 💰.
- **M11.** Не начат (сохранение и полировка).

## Куда положить

Скопировать содержимое этого пака в корень существующего Godot-проекта:

```text
hookahEmpire/
├── project.godot
├── AGENTS.md
└── docs/
    ├── GDD.md
    ├── MVP_PLAN.md
    ├── ARCHITECTURE.md
    ├── PROGRESS.md
    ├── RECIPE_RESEARCH.md
    └── DEV_SETUP.md
```

Эти документы описывают только Garage MVP. Не расширять реализацию в следующие бизнес-этапы, пока MVP не завершён и не пере-скоуплен явно.
